    병합 (Merge)
    
          
    서로 다른 AI 모델의 가중치를 섞어 하나의 새 모델을 만드는 작업입니다. 마치 두 가지 색의 물감을 섞는 것과 비슷해요.
    
          
    양자화 (Quantization)
    
          
    모델의 크기를 줄이는 압축 기술입니다. 32비트 → 4비트로 줄이면 파일이 8배 작아지지만, 약간의 품질 손실이 있어요.
    
          
    GGUF
    
          
    llama.cpp에서 사용하는 모델 파일 형식입니다. 양자화된 모델을 저장하는 표준 포맷이에요.
    
          
    VRAM
    
          
    그래픽 카드(GPU)의 전용 메모리입니다. 모델이 클수록 더 많은 VRAM이 필요하고, 부족하면 작업이 매우 느려지거나 실패해요.
    
          
    HuggingFace
    
          
    AI 모델을 공유하는 플랫폼입니다. GitHub가 코드 저장소라면, HuggingFace는 AI 모델 저장소예요.
    
          
    토큰 (API Token)
    
          
    HuggingFace에 로그인하는 대신 사용하는 "열쇠"입니다. 모델을 업로드하려면 write(쓰기) 권한이 있는 토큰이 필요해요.
    
          
    가중치 (Weights)
    
          
    AI 모델이 학습한 결과물입니다. 숫자들의 집합으로, .safetensors나 .bin 파일에 저장돼요.
    
          
    Q4_K_M / Q5_K_M 등
    
          
    양자화 수준을 나타내는 코드명입니다. 숫자가 작을수록 더 많이 압축 → 파일 작고 빠르지만 품질↓. 숫자가 클수록 품질↑ 파일 커짐.
    
          
    mergekit
    
          
    AI 모델 병합을 자동으로 해 주는 Python 라이브러리입니다. 이 앱이 내부적으로 사용해요.
    
          
    llama.cpp
    
          
    AI 모델을 CPU/GPU에서 효율적으로 실행하기 위한 도구입니다. 양자화(크기 줄이기)를 담당해요.
